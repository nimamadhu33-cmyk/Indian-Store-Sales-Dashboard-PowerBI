Indian Store Sales Dashboard – Power BI

📊 Project Overview

An interactive Power BI dashboard designed to analyze retail sales performance, profitability, customer behavior, and product trends.

🛠️ Tools Used

- Microsoft Power BI
- DAX
- Power Query
- Data Visualization

📈 Key Features

- Sales and profit analysis
- Regional sales performance
- Product and customer insights
- Monthly sales trends
- Sales target vs. actual sales
- Interactive filters and slicers

🎯 Objective

To transform retail data into actionable insights and support data-driven business decisions.
